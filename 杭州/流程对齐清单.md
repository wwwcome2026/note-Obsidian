

**1. 首页 / 启动**  
小程序入口：`pages/index/index`

H5 路由：`/home`，`/` 重定向 `/home`

主要接口：`GET /public/specialty-programs`、`GET /user/bootstrap`、`GET /user/specialty-programs/my-participations`

当前状态：基本对齐

差异点：H5 首页待办可能额外请求 `GET /public/specialty-programs/{programId}`；小程序首页还有“人脸 Demo”入口。

**2. 登录 / 注册 / 微信**  
小程序入口：`pages/login/index`

H5 路由：`/login`、`/register`、`/wechat/callback`、`/bind/mobile`

主要接口：小程序使用 `direct-login`、`direct-mobile-login`；H5 使用 `/auth/patient/h5/*` 登录、注册、微信 OAuth 和绑定手机号接口。

当前状态：H5 功能更完整

差异点：小程序偏微信手机号授权和短信登录；H5 多了注册、密码登录、微信回调、首次绑定手机号。

**3. 实名认证**  
小程序入口：`pages/real-name/index`

H5 路由：`/real-name`

主要接口：小程序主要是实名详情、人脸会话、人脸完成、手工人脸实名提交；H5 增加实名配置、身份证图片上传、OCR、预校验、实名提交、身份证冲突处理。

当前状态：H5 增强

差异点：小程序是姓名/身份证 + 人脸核身；H5 是身份证 OCR + 预校验 + 冲突处理，流程更完整。

**4. 专病活动主流程**  
小程序入口：`pages/specialty/detail/index`，以及待办分流到报名、问卷、权益、预约、报告。

H5 路由：`/specialties/:programId`、`/registration`、`/scale/questionnaire`、`/specialties/:programId/benefit-claim`、`/specialties/:programId/benefit-view`、`/appointment`、`/report`

主要接口：公开活动详情、我的参与状态、创建参与、参与详情、完成模块等专病流程接口。

当前状态：基本对齐

差异点：H5 没有独立 `/specialties` 列表页，会重定向首页；H5 多了 `/shortcut/:mode` 聚合入口。

**5. 报名 / 核销码**  
小程序入口：`pages/specialty/register/index`

H5 路由：`/registration`

主要接口：`GET /user/specialty-programs/participations/{participationId}/registration`、`POST /user/specialty-programs/participations/{participationId}/registration`

当前状态：基本对齐

差异点：小程序是独立报名页；H5 报名和预约复用 `AppointmentView.vue`，通过 route/query 判断模式。

**6. 预约 / 检查**  
小程序入口：`pages/appointment/index/index`

H5 路由：`/appointment`、`/shortcut/appointment`

主要接口：我的参与列表、预约详情、创建预约、更新预约、预约核验码；H5 还覆盖取消预约、完成检查。

当前状态：H5 略增强

差异点：H5 文档覆盖取消预约、完成检查；小程序文档主要描述创建、更新预约和核销码。

**7. 问卷筛查 / 结果授权**  
小程序入口：`pages/questionnaire/index/index`、`pages/questionnaire/result/index`、`pages/questionnaire/access/index`

H5 路由：`/scale/questionnaire`、`/scale`、`/scale/access/:token`

主要接口：当前问卷、提交问卷、结果列表、结果详情、短信授权、分享授权。

当前状态：基本对齐

差异点：H5 明确支持 `templateId` 指定模板、题号导航、确认页；小程序描述为选择后自动下一题。

**8. 权益领取 / 查看 / e签**  
小程序入口：`pages/benefit/index/index`、`pages/benefit/claim/index`、`pages/benefit/view/index`

H5 路由：`/shortcut/benefit`、`/specialties/:programId/benefit-claim`、`/specialties/:programId/benefit-view`

主要接口：公开活动、我的参与、权益领取详情、完成模块、e签发起、e签确认。

当前状态：基本对齐，H5 表达更组件化

差异点：小程序有独立权益列表页；H5 通过 `/shortcut/benefit` 聚合后跳领取或查看。

**9. 报告查看 / 授权**  
小程序入口：`pages/report/index/index`、`pages/report/detail/index`

H5 路由：`/report`、`/shortcut/report`、`/report/access/:token`

主要接口：我的参与列表、报告总览、最新报告、报告授权列表；H5 还覆盖授权目录、授权申请、授权同意、分享授权。

当前状态：H5 增强

差异点：小程序主要展示报告摘要；H5 可按 participation 聚合查看检查报告附件、AI 报告、医生审核报告，并覆盖授权流程。

**10. 保险 / 保单**  
小程序入口：主要在权益查看中体现，文档无独立保险页。

H5 路由：`/insurance`

主要接口：参与详情、保单信息、我的参与列表。

当前状态：H5 独立增强

差异点：H5 有独立保险/保单页；小程序没有单独保险入口。

**11. 家庭关系 / 邀请**  
小程序入口：`pages/family/index/index`、`pages/family/create/index`、`pages/family/invite/index`

H5 路由：`/family`、`/family/create`、`/family/invite/:token`、`/family/request/:id`、`/family/relation/:id`、`/family/share-result/:id`、`/family/face-verify`、`/family/face-verify/callback`

主要接口：家人关系、绑定申请、待处理邀请、解除关系、邀请配置、创建申请；H5 还覆盖邀请 token、身份提交、协议提交、人脸核验、现场代办短信等。

当前状态：H5 明显更完整

差异点：小程序文档只列家庭首页和创建邀请核心接口；H5 覆盖完整绑定闭环。

**12. 我的 / 积分 / 修改密码**  
小程序入口：`pages/profile/index/index`、`pages/points/index/index`

H5 路由：`/profile`、`/points`

主要接口：`GET /user/bootstrap`、`GET /api/user/points/account`、`GET /api/user/points/ledgers`；H5 另有修改密码验证码和提交接口。

当前状态：H5 略增强

差异点：H5 我的页聚合“我的服务”入口，并支持修改密码；小程序主要是资料、实名、积分、家庭、退出。

**13. 文件预览 / 外部分享**  
小程序入口：`pages/webview/index`，以及微信小程序转发。

H5 路由：没有单独 WebView 路由；使用 `/family/invite/:token`、`/scale/access/:token`、`/report/access/:token`

主要接口：H5 使用 `GET /wechat/jssdk/signature?url=...`

当前状态：形态不同

差异点：小程序靠原生 WebView 和小程序转发；H5 靠浏览器链接、微信 JS SDK、公开 URL 构建。

**14. 人脸 Demo**  
小程序入口：首页快捷“人脸Demo”

H5 路由：文档未列独立 H5 Demo 路由

主要接口：`POST /user/face-verify/sessions`、`POST /user/face-verify/sessions/{sessionToken}/complete`

当前状态：小程序独有

差异点：H5 只有实名、家人绑定等业务内人脸核验，没有首页 Demo 入口。
