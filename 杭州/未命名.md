
```
多个前端端口/入口 -> 调用一个或两个后端
```

主要前端有 4 个：

| 前端        | 目录                                                                   | 怎么启动/打开              | 主要调哪个后端                      |
| --------- | -------------------------------------------------------------------- | -------------------- | ---------------------------- |
| 主小程序前端    | `projects/ikunming-main/frontend`                                    | 微信开发者工具导入            | 主工程后端 `8081` + 春城健康后端 `8080` |
| 春城健康管理后台  | `projects/ikunming-chuncheng-health/apps/ikunming-medical-admin-web` | `./run-admin.sh`     | 春城健康后端 `8080`                |
| 春城健康患者 H5 | `projects/ikunming-chuncheng-health-h5`                              | `./run-health-h5.sh` | 春城健康后端 `8080`                |
| 春城健康医生 H5 | `projects/ikunming-chuncheng-doctor`                                 | `./run-doctor.sh`    | 春城健康后端 `8080`                |

后端主要有 2 个：

| 后端     | 目录                                                                 | 启动脚本              | 端口     |
| ------ | ------------------------------------------------------------------ | ----------------- | ------ |
| 主工程后端  | `projects/ikunming-main/backend`                                   | `./run-main.sh`   | `8081` |
| 春城健康后端 | `projects/ikunming-chuncheng-health/apps/ikunming-medical-backend` | `./run-health.sh` | `8080` |

对应关系可以这样理解：

```
主小程序前端
  -> 主工程后端 8081
  -> 春城健康后端 8080

管理后台
患者 H5
医生 H5
  -> 春城健康后端 8080
```

**主小程序比较特殊，会同时连两个后端**；其他几个春城健康页面端基本都连春城健康后端喵。
